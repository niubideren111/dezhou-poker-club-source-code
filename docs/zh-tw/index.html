常見問題

與其他德州專案有什麼區別？

本儲存庫重點是俱樂部、聯盟及社交牌桌；大廳玩法和獨立賽事展示分別由其他專案承載。

從哪個文件開始了解伺服器？

先檢視 ActivityServant.tars 的介面，再閱讀 external 目錄中的非同步登入回呼與建置腳本。
