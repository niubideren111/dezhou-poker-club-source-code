常见问题

与其他德州项目有什么区别？

本仓库重点是俱乐部、联盟及社交牌桌；大厅玩法和独立赛事展示分别由其他项目承载。

从哪个文件开始了解服务器？

先查看 ActivityServant.tars 的接口，再阅读 external 目录中的异步登录回调与构建脚本。
